# LOL Worlds 2026 盤口研究室

公開的賽事市場快照分析。網站為純靜態 HTML，無登入、下單或背景更新。

## 資料範圍

- 初始盤價觀測：2026/10/20 09:40，台灣時間；精確到分鐘，來源盤價更新時間未知。
- 8 場首輪 BO1、13 市場；有報價的獨立業者為 Stake、bet365、BETTERY 共 3 家。
- 只有 GEN–IG、TL–CFO 能跨業者比較。英美 bet365 屬同業，不算兩家獨立樣本。
- 冠軍盤不完整，僅顯示原始隱含機率；完整雙邊與賽區盤採比例去水估計。
- 本機公開 HTTP 更新曾遇 403 或頁面外殼，保留舊快照；此網站不會自行抓取新盤。
- 沒有有效變盤歷史，也沒有隊伍戰力、陣容、版本或藍紅方的獨立模型。

## 使用

打開網站，選擇對戰查看來源、十進位賠率、比例去水機率與觀測時間。支援匯入 JSON（僅目前瀏覽器頁面）及下載 JSON／Markdown 分析。重新整理會還原網站發布時附帶的資料。

## 方法

原始隱含機率=1/十進位賠率。完整市場比例去水機率=該選項隱含機率/全盤隱含機率總和。Overround 是報價超額率，不是業者實際利潤。市場機率不等同獨立預測。

## 更新與來源

新資料須經核實後由維護者重新發布。每筆來源、價格與時間保存在 snapshot.json，頁面中的「來源狀態」保留官方連結與限制說明。沒有價格的來源不補值。

這個儲存庫只包含公開站台成品與公開盤價快照；不包含私人聊天或本機工作紀錄。

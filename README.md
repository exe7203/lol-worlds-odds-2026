- 資料整理時間 UTC：2026-10-22T01:29:14.471Z。
- 盤價觀測範圍 UTC：2026-10-20T01:40:00Z 至 2026-10-22T01:25:00Z；重新觀測公開頁不等於業者盤價實際更新或可成交現價。

- 不完整冠軍盤只顯示原始隱含機率；完整雙邊與賽區盤採比例去水估計。
- 附帶先前有效觀測，可查看同來源前後快照差異；資料不是連續逐筆行情。
- 沒有隊伍戰力、陣容、版本或藍紅方的獨立模型。

## 使用

選擇對戰查看來源、十進位賠率、比例去水機率與各自觀測時間。支援匯入 JSON（僅目前瀏覽器頁面）及下載 JSON／Markdown 分析。重新整理會還原網站發布時附帶的資料。

## 方法

原始隱含機率=1/十進位賠率。完整市場比例去水機率=該選項隱含機率/全盤隱含機率總和。Overround 是報價超額率，不是業者實際利潤。市場機率不等同獨立預測。不同平台的時間與報價限制可造成差異。

## 更新與來源

新資料須經核實後由維護者重新發布。網站不會自行抓取新盤。每筆來源、價格與時間保存在 snapshot.json，頁面中的「來源狀態」保留官方連結與限制說明。沒有價格的來源不補值，讀取失敗不刷新舊價觀測時間。

這個儲存庫只包含公開站台成品與公開盤價快照；不包含私人聊天或本機工作紀錄。

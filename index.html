01 / HOW TO USE

資料與更新

這個網站使用發布時附帶的公開盤口快照。切換對戰查看來源比較，或下載一份 Markdown 分析。

公開站台不會自行抓取新盤。維護者取得可核實的新資料後，需重新建置與發布。部署時間與資料整理時間不代表盤價更新時間。

你可以匯入符合格式的 JSON 快照。檔案只在目前瀏覽器頁面解析，不上傳、不寫回 GitHub；重新整理會恢復網站內附資料。需要保留時請匯出 JSON。

02 / CALCULATION

機率怎麼算

原始隱含機率 = 1 ÷ 十進位賠率。

完整市場的比例去水機率 = 該選項隱含機率 ÷ 所有選項隱含機率總和。

隱含機率總和減 1 是 overround（報價超額率），不等於業者實際利潤。冠軍盤缺選項時無法計算完整市場去水機率。

03 / COMPARABILITY

先比較同一件事

只將同場比賽、同一盤型、同一期間與讓分線的完整市場放在一起。不同業者先各自去水，再比較。

同一 operatorGroup 的不同地區版本只算一家。來源不足兩家時標為單一業者；市場機率不是獨立戰力預測。

盤價時間未同步時，差異可能來自更新時間。讀取時間不是開盤時間，單次快照也不能推斷資金流向。

04 / DATA RECORD

來源與分析邊界

目前含 8 場首輪對戰與 31 個市場。有報價品牌為 5 個、業者集團 4 個，8 場可跨業者比較；各筆快照時間不同，來源清單不等於已接通的業者數。

來源受限與未開出可比較價格都會如實呈現。未取得的價格不補值，也不把業者報價當作某個國家的民意。
